# Clutch Federal Credit Union · account opening demo

A clickable replay of the account opening flow, branded for Clutch Federal Credit Union. Every screen is a frozen copy of the real
product's screens; the cart is live (bundles, ADD, remove, debit card) and carries through to the end. It runs entirely
in the browser: no server, no backend, no network calls, nothing is sent anywhere.

**All data is made up.** The people, phone numbers, SSN digits, addresses, employers, balances and account numbers are
invented for the demo. Typed entries accept any value.

## Open it
Open the site's address (it ends in `/clutch-ao-demo/`). The **Demo Library** lists the 5 paths.

## Use it
Prebuilt paths with made-up people. Every screen is a copy of the real flow. The cart is live: choose a bundle, add or
remove accounts, change the debit card, and it all carries through to the end. Type anything in the fields.
Shortcuts: left and right arrows = previous or next screen; \\ = switch between desktop and phone view; H = show or
hide the control bar; G then L = return to the demo library.
